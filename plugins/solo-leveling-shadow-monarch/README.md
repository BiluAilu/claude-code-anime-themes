# Solo Leveling - Shadow Monarch

An anime-RPG look for the Claude desktop app: three different worlds drawn as layered, animated vector art, a shadow-knight companion that changes with what Claude is doing, a shadow army that grows with every real tool call, and a status band with real figures only. The characters and scenery are original silhouette art (generated by the author, then traced to compact vector paths with `tools/trace.mjs`); there are no screenshots or promotional art from the series. `hooks/art.ts` holds the traced paths; the source images are not shipped.

## The three worlds (`/shadow system | monarch | dungeon`)
- **Monarch** (default): a violet throne room. A gothic throne with a glowing window, a cracked black moon, a castle skyline, a ruined arch framing the knight, drifting mist and smoke, and shadow soldiers (three silhouette types) that grow with each tool call (up to 12).
- **System**: the Hunter's HUD world. A jagged Gate portal over a city skyline, a perspective grid floor, HUD brackets, falling data lines, a scan sweep, a crest, and a status window whose bar is the real context fill.
- **Dungeon**: the Double Dungeon. A red eclipse with glowing cracks, colossal sentinel statues, cracked glowing ground, flame wisps, rising embers and hanging chains.

Each world has its own palette for the whole interface (surfaces, text, accent, git colors, code highlighting) and its own message box shape.

## The companion and real activity
The companion stands in the left margin: the horned shadow knight in Monarch and Dungeon, and a hooded twin-dagger hunter in System. Each state is a different traced pose (standing, sword raised, dash, kneel). What it does follows real events only:
| Session event | Knight and world |
| --- | --- |
| Idle | Breathing, cape sway, slow eyes |
| Turn starts or thinking stream | Rune ring spins above the helm, eyes pulse, more motes |
| Text streaming | Blade glows, sparks rise, energy up |
| Tool call | Dash with afterimages, slash arc, speed lines, shockwave ring; the army grows |
| Turn completes | Knight kneels, one violet flash, expanding ring, then calm after 5 s |
| Tool failure or API error | Red eyes, red vignette and cracks, "penalty" |
| Context 80% or more | Amber vignette; toast at 80% and again at 90% |

Counts, the context percentage and the turn length shown in toasts come from the engine (`tool.call`, `turn.step`, `turn.complete`, `$.session.usage()`). The only timer returns the scene to calm 5 s (6.5 s after an error) after a finish. Nothing is simulated.

## Status band
`◆ SHADOW MONARCH ◆ state │ turns N · tools N · fails N │ ▰▰▰▱▱▱▱▱▱▱ 30%`. The context meter turns amber at 80%.

## Commands
- `/shadow` shows the current world. `/shadow system|monarch|dungeon` switches (remembered across sessions).
- `/shadow status` prints the real event counts this session received. Use it to confirm the integrations work live.

## Install and rollback
Install from a folder: run `claude --plugin-dir <this folder>` (or set `CLAUDE_CODE_PLUGIN_DIRS`), or install from a marketplace that lists it. Rollback: remove the plugin or its folder; your settings are never changed. A session holds one theme at a time, so a theme mod loaded later replaces this look until you run `/shadow` again (and `/godspeed` for the Yato x Killua mod).

## What works and what does not
Works (tested): all three worlds on desktop and mobile, every state in every world, the command, real-event counters, toasts, the status band on terminal and desktop, text contrast (primary at least 10.4:1, muted at least 4.7:1 against the brightest backdrop pixels, framed messages 15:1).

Not supported or not done:
- The terminal and editors draw no theme or backdrop, only the band.
- No sound (not included).
- Scene changes redraw the scene, so the animation restarts on each state change; there is no cross-fade. The scene was kept free of a scene-wide fade because it would blank wherever the app holds the scene still.
- The companion sits in the left margin and is cropped on narrow windows.
- Reduced motion: the app stops the animation and shows the scene at rest.
- Tests exercise the hooks against the documented event shapes; whether your app version draws mod backdrops can only be confirmed by looking.
